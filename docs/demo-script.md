# Two-minute demo

For a screen recording or a live demo. Everything here works today; nothing needs a signed build.
Practise once with your real key so the chat step is not a surprise (it is the part that has not been
rehearsed against a live model by the author).

**Before:** install the app, open it, add an API key in AI settings (or have Claude Code connected).
Close other windows. Light theme reads better on video.

| Time | Do | Say |
|---|---|---|
| 0:00 | Open AFrame on the welcome screen. | "AFrame is a design canvas that an AI can drive. Nothing leaves my computer except what I send to the AI I chose." |
| 0:10 | **Explore the sample project.** Select the cramped pricing page. | "Here is a pricing page I would be embarrassed to ship. Cramped, flat, hard to read." |
| 0:20 | Press **Check**. Point at the count; open the list; press **Fix automatically**. | "It finds contrast, spacing and size problems and fixes the safe ones in one click. One undo takes them back." |
| 0:40 | Open **Chat** (Ctrl+L). Press *Improve the selected frame*. | "Now the AI. It looks at the design, edits it with the same tools Claude Code uses, and checks itself with a screenshot." |
| 0:50 | While it works, expand *Took a screenshot*. | "That is what it is looking at." |
| 1:10 | When it finishes, press **Undo AI change**, then Ctrl+Shift+Z. | "One undo for the whole reply. I stay in charge." |
| 1:20 | Press **A**, drop a note on the headline: "make this bigger". Press *Ask AI to address 1 open note*. | "I can leave notes like a reviewer. It reads them, fixes them and answers." |
| 1:40 | **Export** (Ctrl+Shift+E). Show React + Tailwind, switch to HTML. | "And it is real code: colours stay variables, images become files, names stay stable so a re-export only shows what changed." |
| 1:55 | Save to a folder (or download the zip). | "That folder is yours; the AI can only write where I tell it." |

**If something fails:** Stop, then say what you would do; the recovery page and plain error messages are
part of the product. Do not retry more than once on camera.

**Do not claim:** that macOS or Linux builds are tested, that Figma import has been used on real files,
or that the chat has been benchmarked: the evaluation harness has only a scripted baseline so far.
